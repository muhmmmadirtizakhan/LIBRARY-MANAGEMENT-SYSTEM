# 📚 Library Management System

## 📝 Description
This is a Library Management System built with a **Java backend** and a frontend using **HTML, Tailwind CSS, and JavaScript**. The backend follows **Object-Oriented Programming (OOP)** principles, implementing the three core concepts:

- 🔒 **Encapsulation:** Keeping data safe using private fields and public methods.  
- 🧬 **Inheritance:** Reusing and extending classes to reduce duplication.  
- 🎭 **Polymorphism:** Methods are overridden or overloaded to provide flexible behavior.  

The system allows users to manage books and members efficiently, including **adding, searching, issuing, and returning books**, all through a clean web-based interface.

---

## 🛠️ Tech Stack
- **Frontend:** HTML, Tailwind CSS, JavaScript  
- **Backend:** Java (OOP)  
- **Programming Paradigm:** Object-Oriented Programming  
- **Interface:** 🌐 Web-based UI with responsive design  

---

## ✨ Features
- 📖 Add, update, and delete book records  
- 🔍 Search books by ID, title, or author  
- 📚 Issue and return books  
- 📊 Display all books and member information
