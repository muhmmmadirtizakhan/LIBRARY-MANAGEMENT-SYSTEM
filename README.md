## 📋 Overview 📖
The **Library Management System** is a web-based application that allows users to efficiently manage books and members.  

💡 Built with:
- ☕ Java backend using OOP  
- 🌐 Modern frontend with Tailwind CSS  

✨ It ensures:
- 📚 Organized book management  
- ⚡ Fast operations  
- 🎨 Clean user interface  

---

## 🧠 OOP Concepts Used 🎓

- 🔒 **Encapsulation** — Secure data using private fields & methods  
- 🧬 **Inheritance** — Reusable and extendable class structure  
- 🎭 **Polymorphism** — Flexible method behavior (overloading/overriding)  

---

## ✨ Features 🌟

- 📖 Add, update, and delete books  
- 🔍 Search by ID, title, or author  
- 📚 Issue and return books  
- 📊 Display books and member data  
- 📱 Responsive web interface
